## Notes

- No source returned a 4xx/5xx, so the retry/backoff path was not exercised live; it is covered by mocked tests in `tests/test_http_client.py`.
- No source required cookies, auth headers, or a session to get this initial 200 — all four are open to a plain, low-frequency GET.
- Two of the four sources (`spk_ipo_data`, `spk_web_service_docs`) render meaningfully only via client-side JS. Per the constraints for this phase, we have **not** used Selenium/Playwright/Pyppeteer or attempted to reverse-engineer their runtime API calls — this is recorded as a blocking issue for later phases, not worked around here.
- Raw HTML for every probe is preserved under `data/raw/<source>/<timestamp>/response.html` plus `meta.json` (status, headers, size) for independent verification.
